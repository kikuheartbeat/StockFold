# 自动行情与流水还原

StockFold 1.1：交易流水提供真实买卖、费用和现金变动，网络日线提供持仓期间的实际收盘价，不再需要逐日计算并填写收益。

## 使用步骤

1. 导入最新普通资金流水，或在交易流水页补入买卖、转账。
2. 点击顶部“更新行情”，或进入“历史补录”。
3. 默认从收益记录起点还原到最后一笔流水日期；也可手动调整结束日期。当天数据在16:30后允许更新。
4. 点击“获取行情并计算”，页面显示证券下载进度。下载到的价格保存在本机，下次复用；可勾选重新下载。
5. 查看可完整还原天数、资产快照天数、受保护手工日期和核对明细。
6. 核对提示后勾选保存确认，再点“保存并更新图表”。保存前程序自动生成完整数据库备份。

只按已记录的交易计算。结束日期晚于流水最新日期时，表示假设此后没有尚未录入的资金业务或买卖，不代表程序连接了券商账户。

## 收益与资产口径

- 日末持仓数量：期初持仓加买入、减卖出，已识别的送转股份变动另行计入。
- 个股日收益：日末市值减上日日末市值，加卖出净收款，减买入总支出，加对应红利及税款影响。
- 使用实际资金发生额，避免平均成交价舍入误差，也不重复扣手续费。
- 利息单列为账户其他收益；未知资金事件不自动认作收益。
- 现金按流水结转，并使用原始资金余额作核对锚点。发现余额差异时保留提示，不把差额作为盈利。
- 日末总资产等于现金加全部已确认持仓市值。缺少持仓价格时，不编造总资产。
- 银证转入转出不算盈利，仍以虚线标注在资产柱中。

## 期初持仓

“核对期初持仓”显示整份流水首笔交易前的数量，不是当前还原区间第一天的数量。程序会先处理区间之前的交易。

优先使用人工指定；否则由首个有效“证券余额”减去此前累计股份变化反推，首笔买卖之前的送转股也会扣除。没有依据时暂按0并提示核对，负持仓不视作正确计算。

期初现金优先人工指定，否则尝试用首笔资金余额反推。没有现金信息时，仍可计算股票收益，但资产快照留空。

修改导入交易的日期、证券、数量、价格、费用或金额后，从受影响日期起停用原始现金余额和相关证券余额，按修改后的流水继续结转并提示核对。若首笔依据已失效且没有人工期初数量，收益保留缺口，先核对期初信息再计算。修改证券代码、市场或类型会清除该证券原有行情缓存和手工价格，避免沿用其他证券的价格。

## 行情和缺口

当前使用腾讯公开日线，股票和ETF均取不复权close字段；不接受用前复权或后复权价格替代。请求仅包含市场、证券代码及日期，交易金额和账户余额不发送给行情服务。不增加第三方安装依赖。

清仓后的纯现金区间也能还原，例如只包含利息的日期，无需下载个股价格。网络中断时可重试，重新进入页面会查询服务器现有任务；服务重启后可以重新发起计算。

交易日来自指数日线。历史区间会参考其后已取得的指数交易日来确认休市，最新未确认日期不会猜测为休市。停牌或接口缺价会显示待补价格，不当作零；总收益曲线在数据不完整时保留缺口。

“校准收盘价”可输入指定股票某天的不复权收盘价，支持ETF三位小数。手工校准不会被重新下载覆盖。保存价格后重新计算。

## 手工记录保护

已有手工收益、账户快照或人工日期确认按日期整体保护，自动保存会跳过这些日期。计算预览是独立计算值，受保护日期实际图表仍采用你的手工值。

自动生成日期允许重新计算，会替换本程序以前生成的数据，不重复累加。若手工编辑自动日期并保存，它就变成手工校准日期，后续自动计算会保护它。

预览后如果交易、收益、期初信息或价格发生变化，旧预览不能保存，需要重新计算。

## 备份与升级

数据库结构升级至版本2。升级前自动备份，保存还原结果前也会备份。旧版本1备份可以先校验再升级恢复。

行情缓存、期初覆盖及自动日期归属均包含在数据库备份和完整JSON导出中。恢复备份时必须等待行情任务结束，避免后台任务向恢复后的账户写入旧结果。

默认数据目录为 `data/`，可通过启动参数 `--data-dir` 指定其他位置。

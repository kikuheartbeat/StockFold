# 一级行业31色方案

更新日期：2026-10-21，暖色增补版。股票曲线统一使用一级行业颜色，二级行业保留分类并继承颜色。红绿继续用于收益涨跌，黑色不用于行业。

减少蓝紫色占比，增加鹅黄、粉色、亮橙及暖灰。按用户指定的14个关联组排列；同组颜色相近，通过明暗和饱和度区分。证券分类里的“石油石化”对应用户所说“石油化工”。

可在程序“股票与行业”中点击“查看31色总览”，点击色卡进入该一级行业调整；修改会同步所有二级行业和股票，历史收益金额不变。
